## DESIGN 
Program bertujuan untuk mengelola dan memodifikasi data dalam sebuah database pada mysql. Program memiliki beberapa fitur, yaitu : 
### INSERT
Digunakan untuk menambahkan data baru pada database. Data terdiri dari ID, nama, tahun lahir, email, dan kategori kerja. Insert data memiliki ketentuan yaitu 
* Tahun lahir harus terdiri dari angka saja
* Tidak boleh ada data yang kosong
* ID yang diinsert harus merupakan ID unik (belum ada pada data)
### UPDATE
Digunakan untuk memodifikasi data yang ada pada mysql. 
### DELETE
Digunakan untuk menghapus data pada mysql.
### STRUKTUR KELAS
Data pada mysql tersebut merupakan satu kelas pada java. Kelas tersebut bernamakan "Person" dan terdiri dari 5 atribut : 
* ID
* Nama
* Year
* Kategori
* Email
Kelas tersebut memiliki setter dan getter yang digunakan pada program. 

## ALUR
Alur program sederhana. Diawal, akan ada tampilan menyerupai form, dimana pengguna dapat memasukan data berupa ID, nama, tanggal lahir, email, dan kategori yang terdiri dari 4 options. Dibawah, ada tabel yang berisi seluruh data pada database mysql, yang dimana jika ditekan, pengguna dapat update maupun delete suatu data dalam databse tersebut.
